# Animação

Este diretório é reservado para componentes estritamente visuais de arena, transições, movimento no chaveamento e efeitos. Eles devem receber estado já decidido pelo frontend/API; não calculam resultados, vidas, estratégia, BYE ou avanço oficial.

O agente de Animação é dono desta área. Componentes compartilhados fora dela exigem coordenação prévia com o agente de Frontend.
