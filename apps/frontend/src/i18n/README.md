# Internacionalização do frontend

Mensagens de interface devem ficar em catálogos por idioma, nunca distribuídas pelos componentes. Os locais oficiais são `pt-BR`, `en` e `zh-CN`.

O agente de Frontend deve selecionar e configurar a biblioteca de i18n compatível com o roteamento final antes de criar telas. Consulte [a decisão ADR-002](../../../docs/adr/ADR-002-i18n.md).
