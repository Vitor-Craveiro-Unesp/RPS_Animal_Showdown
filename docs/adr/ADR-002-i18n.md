# ADR-002: Locale-neutral domain data and catalog-based interface text

**Status:** Accepted for architecture; library deferred

## Decision

Represent domain actions and states with locale-neutral identifiers, and render them through catalogs for `pt-BR`, `en`, and `zh-CN`. Do not embed user-facing text in components.

## Rationale

The product requires complete multilingual behavior across gameplay, tournament status, training and spectator views. Separating domain values from copy avoids a later cross-cutting rewrite.

## Deferred

The frontend owner will choose a Next.js-compatible i18n library and routing strategy when creating the first localized flow.
